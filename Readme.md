# Python Setup

Python language used for grap the company data from the website using gst number and get the gem specification data from the gem website using the gem url.

## 1. Activate the MyEnv

To activate the myenv library run the below commands:

    python3 -m venv myenv
    source myenv/bin/activate

## 2. To run the python

To start the python script run the below command
        
        python3 index.py
